# Fictional Google Maps evidence cases

Start with `REVIEW.md` for actual executions, security findings, business-model coverage, and limitations. Four scenario directories contain runnable CLI inputs and actual reports. The standalone HTML fixtures and analysis JSON demonstrate embedded, deferred, and portfolio cases without fetching Google.

All place identifiers, business details, URLs, and key-like fixture strings are fictional. A passing offline test is not a live map verification or a ranking claim.
