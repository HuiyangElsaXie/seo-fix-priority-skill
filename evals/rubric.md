# Evaluation: evidence quality and handoff usefulness

These checks evaluate a bounded workflow, not SEO effectiveness. Test count is not a quality score.

1. Provenance: each recommendation resolves to an actual supplied observation and dated source. Missing fields stay unassessed.
2. Intent: intentionally excluded pages do not receive visibility repair instructions; unknown lifecycle blocks automatic restoration.
3. Priority: business importance can change rank, effort estimates are explicit, review gates dominate numerical score.
4. Uncertainty: stale evidence, canonical differences and partial-crawl zero-inlink signals become investigations. No unsupported orphan/indexed/ranking-loss claims.
5. Actionability: responsible role, next action, dependency/gate and acceptance check are present. No implemented status without execution evidence.
6. Reproducibility: recorded command reruns against committed input; initial output is preserved; review/corrections are versioned honestly.
7. Scope: fictional data is conspicuously labeled; no full-site audit, production verification or measured growth claims.
8. Attribution: upstream bytes, MIT notice, immutable source link and concrete modification map are retained.

Automated coverage: strict types, duplicate/future evidence rejection, empty/missing signals, deterministic ordering, intentional exclusions, stale and ambiguous findings, output contract and source byte integrity. Human/agent review still must judge source truth, real business intent, appropriate platform fix and actual post-deployment result.
